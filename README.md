# MajorLogic Platform

**منصة قرار شراء ذكية وموثوقة**

## ما هو MajorLogic؟
MajorLogic هي منصة قرار تساعد الطلاب على اختيار لابتوب مناسب بطريقة شفافة، مع تقليل ندم الشراء.

### المبادئ الأساسية
- فصل بين معرفة السوق ومحرك القرار
- إظهار الأخبار السيئة في كل توصية
- الشفافية والثقة أولوية
- قابلة للتوسع لمجالات أخرى

## الوضع الحالي (أبريل 2026)
- المرحلة: Phase 0 (التهيئة والأمان)
- تم تنظيف .env
- تم إعداد مجلد docs
- الدومين الحالي: لابتوبات الطلاب الأمريكية

## كيف تبدأ (خطوة بخطوة)

1. إعداد .env
   copy .env.example .env
   افتح .env وأضف قيم Supabase الخاصة بك

2. تثبيت البرامج
   npm install

3. تشغيل الأوامر
   npm run catalog:ingest
   npm run catalog:publish
   npm run demo
   npm test

## هيكل المشروع
- docs/ → التوثيق
- domains/laptop-student-us/ → دومين اللابتوب
- packages/ → الحزم الأساسية
- scripts/ → الأدوات
