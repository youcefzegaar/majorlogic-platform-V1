# MajorLogic Visual & Experience Baseline v1 (Constitution)

## 1. The Core Philosophy
Every visual element in the MajorLogic Platform MUST carry cognitive meaning. If a pixel does not represent data, evidence, or a decision confidence level, it should not exist.

## 2. Semantic Aura System
The "Aura" (glow/background) of a decision card is a mathematical derivation of the decision's soul.
- **Red/Orange (Performance Heavy):** High thermal intensity, high power draw, high score in compute-bound tasks.
- **Cyan/Blue (Mobility/Battery):** High efficiency, light weight, high score in longevity tasks.
- **Purple (Balanced/Gold):** High stability across all vectors, the "Golden Path".
- **Yellow/Gold (Budget Integrity):** High value-for-money ratio.

## 3. Progressive Inspection Architecture
To maintain sub-second performance (Core Web Vitals), media must load in tiers:
- **Tier 1 (Instant):** Static WebP/Avif render (Static Image).
- **Tier 2 (On-Hover):** Parallax/Tilt effect (Low-cost JS).
- **Tier 3 (On-Demand):** Full 3D Inspection Mode (GLB/GLTF) inside a Dedicated Inspection Surface.

## 4. Evidence Overlays
Data overlays MUST be anchored to visual points:
- **Thermal Warnings:** Must be visually placed near exhaust/heat zones.
- **Port Quality:** Must be visually placed near the physical IO ports.
- **Evidence Strength:** Represented by the opacity and "crispness" of the UI element.

## 5. Visual Governance
- No "Hotlinking" to external retail images.
- All assets must pass through the MajorLogic Normalization Pipeline.
- No visual "Entropy": Avoid unnecessary animations that don't signal a state change or a decision insight.

## 6. The Transparency Badge
Every card must carry the Transparency Badge which signals:
- Affiliate status.
- Decision confidence level.
- Source count for the review intelligence.
